# Routes and Pages setup - Collections and Pinned Debug Entries

## Overview

Set up routes and pages for collections and pinned debug entries.

## Requirements

- Create route for collections and make this route accessible when clicked on the Collections link in the sidebar
- The page which displays all collections created by User (3 display cards per row similar to dashboard)
- Clicking on the collection card will display all entries belonging to that collection (same layout)
- Create route for pinned debug entries and make this route accessible when clicked on the Pinned link in the sidebar
- The page which displays all pinned entries of the User (3 display cards per row similar to dashboard)
- Each pinned entry should display the same information as is displayed on the card on the dashboard
